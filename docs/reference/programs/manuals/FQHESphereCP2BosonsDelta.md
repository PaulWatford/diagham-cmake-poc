[FQHESphereCP2BosonsDelta](FQHESphereCP2BosonsDelta.md) allows one to diagonalize the two-body and the three-body contact interactions for bosons on the CP2 geometry. Its usage is similar to that of [FQHESphereCP2GenericInteraction](FQHESphereCP2GenericInteraction.md), but simpler, since it does not require any external file to describe the interaction.
