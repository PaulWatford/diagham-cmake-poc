[FQHESphereCP2FermionEntanglementEntropyParticlePartition](FQHESphereCP2FermionEntanglementEntropyParticlePartition.md) computes the particle entanglement spectrum of a fermionic state generated using [FQHESphereCP2GenericInteraction](FQHESphereCP2GenericInteraction.md). Typical usage is similar to that of [FQHESphereBosonEntanglementEntropy](FQHESphereBosonEntanglementEntropy.md).

Note that the vector must be provided without the discrete <MATH>T_z \rightarrow - T_z</MATH> and Z3 symmetries.
