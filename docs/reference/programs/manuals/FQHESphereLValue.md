Generated option reference: [FQHESphereLValue](../FQHEOnSphere/FQHESphereLValue.md)
FQHESphereLValue computes the mean value of L^2 and L for a given state. The typical usage is 

*\$PATHTODIAGHAM/build/FQHE/src/Programs/FQHEOnSphere/FQHESphereLValue bosons_laughlin2_n_8_2s_14_lz_0.0.vec*

The program detects automatically the statistics, the number of particles, the number of flux quanta and the total Lz value.
