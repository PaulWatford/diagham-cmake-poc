[FQHESphereWithSU2SpinEntanglementEntropyParticlePartition](FQHESphereWithSU2SpinEntanglementEntropyParticlePartition.md) computes the entanglement spectrum and entropy for either the particle partition or the real space partition. It works with both SU(2) spinful fermions and bosons on any genus zero geometry.


- the first column is the number of bosons in the region A
- the second column is the $2S_{z,A}$
- the third column is the number of bosons with a spin up in the region A
- the fourth column is the number of bosons with a spin down in the region A
- the sixth column is  $2L_{z,A}$(or $2K_{y,A}$ for the cylinder geometry)
- the seventh column contains the reduced density matrix eigenvalues
