Generated option reference: [FQHETorusBosonsWithTranslationsGenericNBody](../FQHEOnTorus/FQHETorusBosonsWithTranslationsGenericNBody.md)
FQHETorusBosonsWithTranslationsGenericNBody is the analogue of [FQHETorusFermionsWithTranslationsGenericNBody](FQHETorusFermionsWithTranslationsGenericNBody.md) for bosonic systems on the torus and a generic n-body interaction. By default, the interaction is set to be the n-body hardcore interaction. Notice that if you are interested in this specific interaction and you want to focus on rectangular tori, you should better use [FQHETorusBosonsWithTranslationsNBodyHardCore](FQHETorusBosonsWithTranslationsNBodyHardCore.md).
