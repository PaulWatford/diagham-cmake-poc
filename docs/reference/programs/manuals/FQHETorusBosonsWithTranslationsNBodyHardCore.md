FQHETorusBosonsWithTranslationsNBodyHardCore diagonalizes the hardcore n-body interaction for a bosonic system on the torus geometry. It is the analogue of [FQHETorusFermionsWithTranslationsNBodyHollowCore](FQHETorusFermionsWithTranslationsNBodyHollowCore.md) for bosonic systems and it is also restricted to rectangular tori (see [FQHETorusBosonsWithTranslationsGenericNBody](FQHETorusBosonsWithTranslationsGenericNBody.md) for a more generic still less efficient code).
