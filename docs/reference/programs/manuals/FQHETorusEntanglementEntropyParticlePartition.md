[FQHETorusEntanglementEntropyParticlePartition](FQHETorusEntanglementEntropyParticlePartition.md) allows to compute the entanglement entropy and the entanglement spectrum for partilces on the torus geometry. The system is cut in particle space. Usage is similar to FQHESphereBosonEntanglementEntropy or FQHETopInsulatorEntanglementEntropyParticlePartition. Notice that the states have to be provided without the Kx symmetry.  [FQHETorusEntanglementEntropyParticlePartition](FQHETorusEntanglementEntropyParticlePartition.md) works both for bosons and fermions (the statistics is detected from the input file names).
